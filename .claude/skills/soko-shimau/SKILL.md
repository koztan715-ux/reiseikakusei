# 使ったものをしまっておく

## これは何？

**使わなくなったけれど、捨てるのは惜しいもの**の片付け方です。

作ったスキルやルーチンは、だんだん溜まります。
放っておくと、毎回読み込まれて邪魔になります。かといって消すと、二度と使えません。

**そこで「倉庫」を作ります。**

## 倉庫とは

- **普段は読み込まれない場所**（自動で読まれるフォルダの外）
- でも**消えていない**
- 目次（INDEX）を置いておいて、**必要なときだけ見に行く**

## こう言ってください

しまうとき:
```
〇〇はもう使わないので、倉庫に入れてください。
```

出すとき:
```
前に〇〇みたいなのを作りましたよね。あれを出してください。
```

## しまう手順（順番が大事）

1. **先に、動いている設定を止める**
   ★これを忘れると、倉庫に入れたのに動き続けます
2. フォルダを倉庫に移す
3. **目次に1行書く**（何をするものか／どんなときに使い回せるか）

## 目次に書くこと

ただファイル名を並べても、あとで分かりません。**こう書きます。**

```
| フォルダ名 | 中身 | 使いどころ |
| イベント直前の集計 | 開催2日前から数時間おきに申込を集計 | 次のイベントで時刻を変えれば同じ形が組める |
```

**「使いどころ」の列が大事です。** これがあると、半年後の自分が思い出せます。

## 出すときのルール

**倉庫の原本は書き換えません。**
コピーして、新しい名前で作り直します。そうすれば、また次も使えます。

## こんなものを入れておくと便利

- 1回限りのイベント用に作ったもの（次のイベントで雛形になります）
- 季節もの（年に1回使うもの）
- 実演用・お試しで作ったもの
- 別のやり方に切り替えて、使わなくなった古い版

## 自分用に直すところ

- 倉庫の場所（作業フォルダの中に `_倉庫` を作るのがおすすめです）
- 目次の書き方
