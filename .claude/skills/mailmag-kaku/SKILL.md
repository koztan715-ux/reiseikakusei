# メルマガを書く

## これは何？

定期的に送るメルマガの本文を書きます。
毎回ゼロから悩まなくていいように、**書き出しから締めまでの型**が決まっています。

## こう言ってください

```
今日のメルマガを書いてください。
今日伝えたいのは〇〇です。
```

テーマが決まっていなければ、こちらから提案します。

## 全体の型

```
（1）書き出し＝今日の時事ネタ
（2）そこから本題への橋渡し
（3）【1】本題（読む人の得になる話）
（4）【2】以降のお知らせブロック
（5）締め
（6）署名・配信解除リンク
```

## 書き出しは必ず「時事ネタ」から

**その日ならではの話から入ります。** そうすると「今日のメルマガ」になります。

| 使っていい | 使わない |
|---|---|
| 季節の行事・連休・天候・旬の食べ物 | 政治・選挙 |
| スポーツの好記録・記念日 | 事件・事故・訃報 |
| 楽しい新商品・今日は何の日 | 戦争・炎上・不祥事 |
| **心配事（台風・大雨・猛暑・寒波）** | 誰かの病気 |

**心配事はむしろ歓迎です。** ただし扱い方を変えます。
危険を煽る報道の口調にせず、「無理をなさらず」「予定より、あなたが無事でいることのほうが大事」と
**読む人の側に立って心配します**。この段落だけは顔文字を使わず、やさしい丁寧語で書きます。

そして**時事ネタは必ず本題につなげます**（触れっぱなしにしない）。
例：台風で連休の予定が崩れる → 予定が崩れたときこそ信用が動く、へ。

## 本題の書き方

### 見出しに商品名を出さない
「宣伝です」とバレると、そこで読み飛ばされます。見出しには**読む人の変化**を書きます。

### 詳細はリンク先に集約する
本文で情報を出し切ると、リンクを開く理由が消えます。
告知は「見出し＋URL＋期限」の3つまで。

### 毎日（毎回）、本文をまるごと書き直す
書き出しだけ変えて、あとは使い回す——これをやると読者は気づきます。
**前回と同じ例え・同じ数字を続けて使わないでください。**
書く前に前回分を読み返します。

## 読みやすさの作り方

- **1文1行**。長い文は読点で改行して2〜3行に割る
- 段落の間は空行1〜2行
- 見出しは**全角20字以内**（罫線の幅に収める）
- 整った書き言葉ではなく、**しゃべっているままの口語**で
  - 「〜なんですよね」「〜しちゃう」「で、」「ほんとに」
  - 顔文字は1通に6〜8個が目安（付けすぎると軽くなります）
  - ただし**URL・期限・価格・会場などの事実情報は崩さない**

書き終えたら音読して、しゃべらない言い回しを口語に直します。

## 件名の作り方

**件名は、本文を読むかどうかの唯一の判断材料**です。
時事ネタに合わせず、**読む人の得**を主役にします。

- 入れる → 具体的な数字か結果（「毎朝1時間の作業をやめました」）／「どうやって?」が残る引き
- 避ける → 中身が想像できない件名／煽り・断罪／商品名
- 長さ15〜30字
- **毎回2〜3案つくって、いい順に並べる**

## 自分用に直すところ

- 一人称（僕／私）— 混在させないこと
- 顔文字の種類と量（自分の柄に合わせてください。使わない人は使わなくていい）
- ブロックの数と並び（【1】【2】…の構成）
- 署名と配信解除リンク
