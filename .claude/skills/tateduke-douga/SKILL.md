# 縦動画を仕上げる

## これは何？

スマホで撮った「喋っている縦動画」を、そのまま投稿できる形に仕上げます。

1回の指示で、ここまでやります。

1. **無音の間をカット**
2. **「えーとー」「あのー」をカット**
3. **間延びした語尾を詰める**
4. **文字起こしして、字幕を焼き込む**
5. **BGMを合成**

60秒の動画が、**40秒ほどで仕上がります。**

## ⚠️ はじめに1回だけ、準備が必要です

| | |
|---|---|
| **時間** | 15〜30分（初回だけ） |
| **パスワード** | 途中でパソコンのパスワードを聞かれます。**そこだけはご自分で打ってください** |
| **容量** | 1GBほど |
| **Windowsの方** | Macより手順が増えます |

### 準備のしかた

```
動画編集の道具をそろえてください。
```

## 使い方

```
この動画を仕上げてください。
（ファイルを指定する。スマホから送った動画なら「ダウンロードの中のIMG_1234で」でOK）
```

## 調整できること

| 項目 | 内容 |
|---|---|
| 字幕の位置 | 上からの割合で指定（0.6＝やや下） |
| 字幕の文字サイズ | 大きめが読みやすい |
| BGMの音量 | 喋り声とのバランス |
| 無音と判定する長さ | 短くすると細かく詰まる |

「字幕をもう少し上に」「BGMを小さく」と言えば調整します。

## ★仕上がりは必ず目で見てください

自動で検証もしますが、**字幕が顔にかぶっていないか、画面からはみ出していないか**は、
数値では分かりません。

長いセリフの場面（字幕が3行になるところ）を選んで、静止画で確認してください。

## 仕組み（興味のある方へ）

**「えーとー」はなぜ消せるのか。**
「えーとー」は音が出ているので、無音を探す方法では見つかりません。
そこで**音色の変化の少なさ**を使います。伸ばし音は音色が変わらないという性質があります。

また、**丸ごと消す場合と、語尾を詰めるだけの場合を区別**しています。
語尾ごと消すと言葉が壊れてしまうためです。

## 自分用に直すところ

- BGMの曲（自分の好きな曲に差し替えられます）
- 字幕の位置・サイズ・色の既定値
- 元の動画の置き場所
