# 研修資料を作る

## これは何？

企業研修や連続講座で使う資料を作ります。

**講演スライドとは作り方が正反対です。** ここを間違えると、使えない資料になります。

## 講演と研修のちがい

| | 講演会の資料 | 研修の資料 |
|---|---|---|
| 1ページの情報量 | **少なく** | **しっかり詰める** |
| 画像 | 豊富に | 必要な分だけ |
| 枚数 | 多くてOK | 枚数より密度 |
| 目的 | その場でイメージを湧かせる | **あとで読み返して再現できる** |

### なぜ研修は詰めるのか

**研修資料は、研修の報告書の一部として使われるからです。**
受講者や、研修を発注した会社の人が、あとから読み返します。
そのとき「1枚で自立して読める」密度がないと、資料として機能しません。

枚数を増やして薄めるのではなく、**1枚で完結させます**。

## こう言ってください

```
研修資料を作ってください。
テーマは〇〇、時間は△時間、受講者は□□の方々です。
```

## 迷ったら最初に確認すること

**「これは講演会ですか、研修ですか」**

- セミナー・講演会・イベント登壇 → 低密度型（別スキル「koen-slide」）
- 研修・連続講座・社内教育 → 詰め込み型（このスキル）

分からなければ聞いてください。ここを取り違えると、作り直しになります。

## レイアウトの鉄則（講演スライドと共通）

- 下で切れない（完成後に機械でチェック）
- 変なところで折り返さない
- 全ページで見出しの高さを揃える
- 文字の色を薄くしない
- 印刷したときに背景写真が消えないようにする

## 自分用に直すところ

- 配色とフォント
- 1ページあたりの情報量（「もう少し詰めて」「減らして」で調整します）
- 演習・ワークの入れ方
