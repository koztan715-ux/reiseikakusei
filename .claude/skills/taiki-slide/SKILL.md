# セミナーの待機スライドを作る

## これは何？

オンラインセミナーの開始前に映しておく1枚を作ります。
**ただの「まもなく開始します」ではありません。**

この1枚で、場のあたたまり方が変わります。

## 入れるもの（4つ）

### 1. BGM（複数から選べる）
その場で曲を選べるようにします。音源は商用利用OK・クレジット不要のものを使ってください。
（フリーBGMサイトから4曲ほど用意しておくと便利です）

### 2. 音量スライダー
0〜100%で調整できるように。既定は35%くらいがちょうどいいです。再生・停止ボタンも付けます。

### 3. 参加者への4つのお願い

この文面をそのまま使ってください。

> ① できればカメラをONに（顔が見えると、場があたたまります）
> ② 表示名を、お名前に変えてください（参加者一覧 › ご自分の名前 › 詳細 › 名前の変更）
> ③ 顔出しが難しい方は、お名前の前に「👂」を（「聞いています」の合図。聞き役での参加も大歓迎です）
> ④ リアクションは大きめに（拍手も 👍 も、どんどんお願いします）
>
> ここは学ぶ場であり、つながる場でもあります。

**③の「👂」がポイントです。** 顔出しできない人に居場所を作ると、参加率が落ちません。

### 4. Zoomの注意書き
「画面共有のとき『コンピュータの音声を共有』にチェックを入れるとBGMが届きます」

これを書いておかないと、自分には聞こえているのに参加者には無音、という事故が起きます。

## こう言ってください

```
待機スライドを作ってください。
セミナー名は〇〇、開始は△時です。
```

## 自分用に直すところ

- 配色（本編のスライドと合わせる）
- BGMの曲（増やすときは音源ファイルを足して、リストに1行足すだけ）
- カウントダウン表示を入れるかどうか
- お願いの文面（基本はそのままがおすすめです）
