# SNSシェア用の画像を用意する

## これは何？

自分のページのURLを X・LINE・Facebook・Note などに貼ったとき、
**カードに出てくる画像**のことです。これを「OGP画像」と言います。

設定していないと、画像なしの寂しいカードになります。**クリック率が全然違います。**

## こう言ってください

```
〇〇のページのOGP画像を作ってください。
```

## 画像のサイズ

| 項目 | 値 |
|---|---|
| サイズ | **1200 × 630 ピクセル** |
| 形式 | JPG |
| 容量 | 100〜150KB程度 |

大きめ（2400×1260）で作ってから縮めると、きれいに仕上がります。

## 作るときのコツ

### 1. 変わる情報を画像に入れない
**締切日・残席数・価格は入れないでください。**
入れると、変わるたびに作り直すことになります。使い回せる内容にします。

### 2. ページの配色に合わせる
ページを開いたときの印象と、カードの印象がずれると違和感が出ます。

### 3. 文字は大きく、少なく
スマホでは小さく表示されます。**タイトルだけ**で十分です。

## 設定する場所

### 自分のサイトの場合
ページの `<head>` の中に、og: で始まる指定を書きます。画像は絶対URLで指定します。

### 配信システム・ページ作成サービスの場合
たいてい「ページ設定」の中に「SNSシェア設定」という項目があります。
そこに画像をアップロードします。あわせて「ページ説明」も埋めておくと、カードに説明文が出ます。

## 設定したのに画像が出ないとき

**SNS側が古い情報を覚えているだけ**のことがほとんどです。

- X → カードバリデータで再取得
- Facebook → シェアデバッガーで再取得
- Note → リンクを貼り直す

## 自分用に直すところ

- 配色とフォント
- ロゴを入れるかどうか
- 画像の置き場所
