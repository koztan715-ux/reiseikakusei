# 出版企画書を作る

## これは何？

本を出したい人が、出版社の編集者に渡す「企画書」を作るスキルです。
企画のタネ（こんな本を出したい、という話）を伝えるだけで、編集者が判断できる形に組み上げます。

**いちばん大事な考え方**: 企画書の役割は、**編集者に判断材料を差し出すこと**です。
自分で「これは売れます」と言うことではありません。事実を並べて、結論は編集者に思わせます。

## こう言ってください

```
出版企画書を作ってください。
テーマは〇〇で、読んでほしいのは△△な人です。
私の仕事は□□で、これまで〜をしてきました。
```

足りない情報があれば、こちらから質問します。

## 作る順番

1. 書名・サブタイトル・著者名
2. 書籍概要
3. 著者プロフィール
4. 類書と、この企画が売れる理由
5. 過去の出版実績と、その販促の実態（初めての出版なら、代わりに発信実績）
6. 章立て・構成案（章タイトル＋項目を1行ずつ）

## 守ること（これを外すと編集者に嫌われます）

### 1. 自分で自分の企画を評価しない
「いま、この本を出す意味は大きい」「売れる企画だ」——こういう文は**全部消します**。
消しても情報が減らない文は、書かないほうがいい文です。
かわりに、読者の不安・市場の動き・実績といった**事実**を並べます。

### 2. 編集者に市場を解説しない
相手は出版のプロです。「〇〇ジャンルは意外と当たっていない」のような断定はしません。
見立てを書くときは「〜と考えている」と、あくまで提案側の見解として書きます。
「ここで強調したいのは」のような、読み方を指図する表現も使いません。

### 3. 著者の呼び方は「著者は」
姓の呼び捨て（「田中は」）は使いません。主語なしで書ける文は、主語を立てません。

### 4. プロフィールは自叙伝にしない
①肩書き・経歴（客観）→②テーマに直結するキャリアの核（エピソード1つ程度）→③実績・考え方→④本書テーマへの接続、の流れ。
時系列で私事を逐一書くのはNGです。本人が語った言葉は「著者は『…』と振り返る」の形で客観化できます。

### 5. メモ書き・解説を残さない
タイトルの意図説明、別案（参考）、「※予算は口頭で」のような注記、末尾の作成メモ——
提出版からは**すべて削除**します。そういう調整ごとは口頭か別の紙で。

### 6. 人間が書いた見た目にする
カード・色のブロック・アイコンで飾りません。**見出しと本文だけのプレーンな文書**にします。
飾ると「AIが作った」と見抜かれて、それだけで信頼を落とします。

### 7. 数字は算用数字（1, 2, 3…）

### 8. 販促・実績は「事実の箇条書き」だけ
実売数・完売実績・読者数・集客実績など、**確かめられる事実だけ**を箇条書きにします。
「つまり〜を示せる」のような解釈の文は書きません。金額（予算・投下額）も書きません（口頭で調整）。

### 9. 章立ての前に、設計意図の解説を置かない
「シーン別に構成しました」「関係が深まる順に並べました」——並びを見れば分かることは書きません。
**構成のよさは、構成そのもので示します。**

### 10. コピー調の表現を使わない
本の擬人化（「本書が手渡すのは」）、比喩の飾り（「武器」「ほどいていく」）——
これはLPや帯の言葉であって、企画書の言葉ではありません。
「本書では〜をまとめる／解説する」と平易に書きます。売り文句を考えるのは編集者の仕事です。

### ★迷ったら消す
「〜で決まります」「この本の生命線です」「ほかの誰も書けない」——
価値を断定する煽り文は、**わざとらしく胡散臭く**見えます。項目の意図説明は原則いりません。

## 自分用に直すところ

- 分量（プロフィールは1,000字前後が目安。相手の指定があればそちらを優先）
- 章立ての数（4〜6章×各10項目あたりが一般的）
- 書き出す形式（Word、テキスト、PDFなど。相手の希望に合わせます）
