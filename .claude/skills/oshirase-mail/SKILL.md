# お知らせメールを書く

## これは何？

イベントやセミナーの案内メールを書きます。
**書くだけでなく、送る前の「抜けチェック」までやります。**

## こう言ってください

```
〇〇のお知らせメールを書いてください。
日時は△△、場所は□□、申込はこのURLです。
送る相手は〜な人たちです。
```

## 書くときの形

```
（あいさつ・本題への入り口）

（何のお知らせか・相手にとって何がいいか）

━━━━━━━━━━━━━━━━━━━━

【詳細はこちら】

▼〇〇（イベント名）
https://〜

□月□日まで

━━━━━━━━━━━━━━━━━━━━

（背中を押す一言）

（署名）
```

## 守ること

### 1. 詳細は全部書かない。リンク先に任せる
日程表・料金表・特典リストを本文に貼ると、**リンクを開く理由が消えます**。
本文の告知ブロックは「**見出し＋URL＋期限**」の3つまで。

### 2. 改行を多く。1文1行を基本に
スマホで読まれます。詰まった段落は、読む前に飛ばされます。
- 長い1文は、意味の切れ目で2〜3行に割る
- 話題が変わったら空行を1〜2行

### 3. 見出しは全角20字以内
罫線（━が20個）の幅に収めます。超えると折り返してガタつきます。

### 4. 見出しに商品名・イベント名を出さない
見出しで「宣伝です」とバレると、そこで読み飛ばされます。
見出しには**読む人の変化や状態**を書きます。商品名は下のURLブロックで出せば足ります。

### 5. ★URLは必ずメールに書く
LINEやチャットだけで案内を済ませない。**メールにも必ず同じURLを載せます。**
他のところだけで案内すると、「届かない」「見つけられない」人が必ず出ます。

### 6. 件名は「開く理由」を書く
- 入れる → 具体的な数字か結果／「どうやって?」が残る引き／期限があれば頭に【本日最終日】
- 避ける → 件名だけで中身が想像できないもの／煽り・断罪／商品名
- 長さは15〜30字

## 送る前チェック（必ず通す）

| チェック | 内容 |
|---|---|
| URL | 本文に入っているか。**実際に開いて確認したか** |
| 日時 | 曜日は合っているか（「9月3日（火）」の曜日ズレは事故のもと） |
| 問い合わせ先 | 返信できるアドレスか（送信専用アドレスを書いていないか） |
| 「このメールには返信できません」 | 送信専用から出すなら明記したか |
| 配信解除リンク | メルマガ配信なら必ず末尾に |
| テスト送信 | **本番前に自分宛てに送って、実機で目を通したか** |

**最後のテスト送信は省かないでください。** リンク切れ・文字化け・レイアウト崩れは、
画面の上では見えず、実際に届いたメールで初めて見えます。

## 自分用に直すところ

- 署名（会社名・連絡先）
- 一人称（僕／私）と文体
- 罫線の記号と幅
