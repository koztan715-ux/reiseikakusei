# 指示文を整える

## これは何？

「頼んだのに、思ったものが出てこない」

それは**頼み方の問題**であることがほとんどです。
このスキルは、うまくいかない頼み方を、伝わる形に直します。

## ★3つ書くだけ

難しい呪文はいりません。**この3つを書くだけです。**

| # | 書くこと | 例 |
|---|---|---|
| **①** | **私がしていること／したいこと**（状況・目的） | 社内報の担当で、今回の結果を社員に伝えたい |
| **②** | **してほしいこと**（依頼） | この箇条書きを記事にして |
| **③** | **そのための条件**（分量・トーン・形） | 600字・専門用語なし・前向きなトーンで |

### たとえで言うと

**新しく入った優秀な部下に頼むつもりで書く。**

優秀な人でも、状況を知らなければ的外れなものを作ります。
逆に、状況さえ分かれば、細かく指示しなくてもいいものを作ります。

## 悪い例 → いい例

### ✕ 悪い例
```
春闘の結果をまとめて
```
→ これだと、誰に向けた何のためのまとめか分からないので、当てずっぽうになります。

### ○ いい例
```
①機関紙の担当をしていて、春闘の結果を組合員に伝えたい
②この箇条書きを記事にしてほしい
③600字・専門用語なし・前向きなトーンで
```

## こう言ってください

```
この指示を整えてください。
「〇〇して」と頼みたいです。
```

または、うまくいかなかったときに、

```
思ったのと違うものが出てきました。頼み方を直してください。
```

## よくある「足りないもの」

| 足りないもの | 起きること |
|---|---|
| **誰に向けたものか** | トーンがずれる |
| **何に使うのか** | 形式がずれる（メール用なのに資料が出てくる等） |
| **どれくらいの長さか** | 長すぎる・短すぎる |
| **今どういう状況か** | 前提のズレた提案が出てくる |

## 自分用に直すところ

- よく使う条件（文体・長さ・トーン）を書き留めておくと、毎回書かなくて済みます
  → 「rule-oboesaseru」スキルで覚えさせられます
