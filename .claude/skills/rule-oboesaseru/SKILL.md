# ルールを覚えさせる

## これは何？

**毎回同じことを説明していませんか。**

「数字は算用数字で」「この言い方はやめて」「いつもこの形で出して」——
こういうものは、**一度覚えさせれば、二度と言わなくて済みます。**

これが、クロードコードを使ううえで**いちばん効く工夫**です。

## こう言ってください

```
これを覚えておいてください。
〇〇のときは、△△してください。
```

## 覚えさせる場所は2種類

| 場所 | 何を入れるか | 特徴 |
|---|---|---|
| **CLAUDE.md** | 毎回必ず守ってほしいこと | 毎回読まれる。短く書く |
| 記憶ファイル | 案件の背景・調べたこと | 必要なときだけ読まれる |

### CLAUDE.md とは

**自分の作業フォルダに置いておく「決まりごとの紙」**です。
毎回かならず読まれるので、ここに書いたことは必ず守られます。

**ただし、長く書きすぎないでください。** 毎回読むものなので、
長いと大事なことが埋もれます。**1つのルールは1〜2行**にします。

## 良いルールの書き方

### ✕ 悪い例
```
文章を書くときは読みやすくしてください
```
→ 「読みやすく」が人によって違うので、守れません。

### ○ 良い例
```
文章の読点は1文に0〜2個まで。20〜25字に1つが目安
```
→ 判断できる基準になっています。

### ルールに入れるといいもの

| 種類 | 例 |
|---|---|
| **やってほしいこと** | 資料はPDFではなくHTMLで作る |
| **やってほしくないこと** | 「〇〇コンサルタント」という肩書きは使わない |
| **理由** | ←これが大事。理由があると応用が効きます |

## 「なぜ」を書くと、応用が効きます

```
✕ 領収書は完了メールと同時に送る
○ 領収書は完了メールと同時に送る（あとから個別に頼まれると全部手作業になるため）
```

理由が書いてあると、**似た場面でも同じ判断ができます。**

## こまめに増やしていくのがコツ

最初から完璧なルールを作ろうとしないでください。

**「あ、また同じこと言ってる」と思ったら、その場で覚えさせる。**
これを続けると、半年後には自分専用の道具になります。

## 自分用に直すところ

- CLAUDE.mdを置く場所（いつも作業するフォルダ）
- ルールの分け方（仕事の種類ごとに見出しを作ると探しやすいです）
