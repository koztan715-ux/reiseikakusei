# 自己紹介・プロフィールを作る

## これは何？

講演やイベントで毎回求められるプロフィールを作ります。
**長さの違う3種類をまとめて作る**ので、次からは使い回せます。

| 種類 | 長さ | 使うところ |
|---|---|---|
| 短い | 50〜80字 | SNSの自己紹介、名刺、チラシの隅 |
| 中くらい | 200〜300字 | イベントページ、登壇者紹介 |
| 長い | 800〜1,200字 | 書籍の著者紹介、企画書、公式サイト |

## こう言ってください

```
プロフィールを作ってください。
仕事は〇〇で、これまで△△をしてきました。
使うのは□□（講演／書籍／サイト）です。
```

## 書き方の順番（長いバージョン）

1. **肩書き・経歴**（客観的な事実から入る）
2. **テーマに直結するキャリアの核**（エピソードは1つ程度）
3. **実績・考え方**
4. **今の仕事・テーマへの接続**

## 守ること

### 1. 自叙伝にしない
時系列で私事を逐一書くのはNGです。読む人が知りたいのは「この人は何者で、なぜこの話ができるのか」です。

### 2. 実績は事実だけ
確かめられる事実を書きます。「業界で高く評価されている」のような自己評価は入れません。

### 3. 数字は算用数字で

### 4. 使う場面に合わせて肩書きを変える
同じ人でも、書籍なら「著者」、講演なら「講演家」のように主役の顔が変わります。
**使わない肩書きがあれば先に伝えてください**（それは絶対に出しません）。

### 5. 自慢を繰り返さない
同じ実績を何度も出すと、読む人は疲れます。いちばん効く1つに絞ります。

## 自分用に直すところ

- 使わない肩書き（NGワード）
- 必ず入れたい実績
- 文体（です・ます／だ・である）
- 写真を添える場合の指定
