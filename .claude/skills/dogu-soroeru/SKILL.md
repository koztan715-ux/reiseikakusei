# 道具をそろえる

## これは何？

**文字起こし**と**動画編集**のスキルを使うために必要なソフトを入れます。

ほかのスキルは何も準備せずに使えますが、この2つだけは道具が要ります。

## 入れるもの

| 道具 | 何のため | 使うスキル |
|---|---|---|
| ffmpeg | 音を取り出す、動画を切る、BGMを合わせる | 文字起こし・動画 |
| whisper（文字起こしソフト） | 音声を文字にする | 文字起こし・動画 |
| 文字起こしの部品（1.5GBほど） | 日本語を聞き取るためのデータ | 文字起こし・動画 |
| Pillow（画像の部品） | 字幕の文字を描く | 動画のみ |
| numpy（計算の部品） | 無音や「えーとー」を見つける | 動画のみ |

## 手順（クロードコードがやること）

### 1. まず、何が入っているか確認する
すでに入っているものは、入れ直しません。

### 2. Macか Windowsかを見る
使っているパソコンに合った方法で進めます。ご自分で判断する必要はありません。

### 3. 順番に入れていく

**Macの場合**
1. Homebrew（ソフトを入れるための道具）が入っているか確認。無ければ入れる ← ここでパスワードを聞かれます
2. `brew install ffmpeg`
3. `brew install whisper-cpp`
4. 文字起こしの部品を **`~/whisper-models/ggml-large-v3-turbo.bin`** にダウンロードする（1.5GB）

**Windowsの場合**
1. winget または Chocolatey で ffmpeg を入れる
2. whisper.cpp を入れる（環境によって手順が変わります）
3. 文字起こしの部品を **`%USERPROFILE%\whisper-models\`** に置く

### ★部品の置き場所は必ずこの場所にしてください
スキルの中のプログラムが、この場所を見に行きます。
別の場所に置くと「部品が見つかりません」と出ます。

### ★Pillow と numpy を入れる python に注意（動画のスキルを使う人だけ）
パソコンには python が何種類か入っていることがあります。
**動画のスキルを動かすときに使う python に入れてください。**

Macでは `/usr/bin/python3` に入れるのが確実です。

```
/usr/bin/python3 -m pip install --user Pillow numpy
```

入れたあと、動画のスキルを動かすときも同じ `/usr/bin/python3` を使います。
（間違えると「必要な部品が入っていません」と出ますが、そのメッセージに直し方が書いてあります）

### 4. 動くか確かめる
短い音声で実際に試して、ちゃんと文字になるか確認します。
**ここまでやって、初めて「準備完了」です。**

## ⚠️ 使う方へ：3つだけ知っておいてください

### 1. 時間がかかります
**15〜30分**見ておいてください。特に文字起こしの部品は1GBあるので、
ネットの速さによっては時間がかかります。**初回だけ**です。

### 2. パスワードを聞かれます
ソフトを入れるとき、**パソコンのパスワード**が必要になります。

**これだけは、ご自分で打ってください。** クロードコードはパスワードを打てません（安全のためです）。
「パスワードを入れてください」と出たら、ご自分でキーボードから入力してください。

### 3. うまくいかないことがあります
特にWindowsは、環境によって手順が変わります。
**途中で止まったら、そのまま質問してください。** 別の方法を探します。

無理に進めず、正直に「ここで止まりました」と伝えるのが一番早い解決になります。

## 準備が終わったら

こう言うだけで使えます。

```
この音声を文字起こしして
```
```
この動画を仕上げて
```

ありません。1回終われば、二度と触らなくて大丈夫です。
