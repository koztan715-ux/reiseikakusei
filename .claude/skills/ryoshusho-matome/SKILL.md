# 領収書をまとめる

## これは何？

**ダウンロードボタンが無いサービスの領収書**を、毎月まとめてPDFにして保管します。

決算のときに慌てて1年分を探すことになりがちですが、
**月1回まとめておけば、決算は一瞬で終わります。**

## こう言ってください

```
先月の領収書をまとめてください。
```

## 対象になりやすいサービス

| 種類 | 例 |
|---|---|
| メールで届くだけのもの | アプリの課金、サブスク |
| 管理画面にあるが、DLボタンが無い | SNS広告、配信システム |
| ログインしないと見られない | クラウドサービス |
| 紙が来ない | 印刷サービス、宿泊予約、交通 |

## 進め方

### 1. 対象のリストを作る（最初の1回だけ）
毎月払っているものを全部書き出します。**この一覧を作るのが一番大事です。**
一度作れば、毎月同じものを見に行くだけになります。

### 2. 「先月分」を取りに行く
月初に実行するのが基本です（例：10月に実行 → 9月利用分）。
その月の請求が確定してから取りに行かないと、取りこぼします。

### 3. PDFにする
画面しかないものは、印刷 → PDFで保存、で作れます。

### 4. 分かる名前を付ける

```
領収書_サービス名_年月_金額.pdf
例：領収書_〇〇サービス_202609_16500円.pdf
```

あとで探すときに、**ファイル名だけで判断できる**ようにします。

### 5. 決まったフォルダに入れる
領収書は**1か所に集約**してください。散らばると決算で詰みます。

## 気をつけること

- **取りこぼしチェック**: 対象リストと突き合わせて、全部そろったか確認する
- **金額を控える**: ファイル名に入れておくと、集計が早くなります
- **メールで届くものは、フォルダ分けかラベルをつけておく**と毎月探さずに済みます

## 自分用に直すところ

- 対象サービスのリスト（★ここが一番大事。自分の契約に合わせて作ってください）
- 保存先フォルダ
- 決算の月（それに合わせて年度の区切りを決めます）
