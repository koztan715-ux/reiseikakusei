# 1枚のLPを作る

## これは何？

売りたいもの・募集したいものの**申込ページ**を、1枚のHTMLで作ります。

LP（ランディングページ）とは、**1ページで全部を伝えて、申し込んでもらう縦長のページ**のことです。

## こう言ってください

```
LPを作ってください。
売りたいのは〇〇、価格は△△、申込の締切は□□です。
届けたい相手は〜な人です。
```

## 入れるもの（上から順）

1. **ヘッダー画像＋キャッチコピー**（15字以内。別スキル「catch-copy」で作れます）
2. **こんなことで困っていませんか**（読む人の状況）
3. **これで解決します**（何が手に入るか）
4. **中身の説明**（日程・カリキュラムなど）
5. **話す人／作った人は誰か**
6. **お客様の声**（あれば。数字と具体があるものを）
7. **価格**（比較価格があれば添える）
8. **よくある質問**
9. **申込ボタン**（★ページの途中に何度か置く。最後だけではダメ）

## 大事なこと

### 申込ボタンは複数置く
最後まで読んでから申し込む人ばかりではありません。
**気持ちが高まった瞬間に押せる位置**にボタンを置きます。画面下に追従するボタンも有効です。

### スマホで見て作る
ほとんどの人がスマホで見ます。パソコンの画面だけで作って満足しないでください。

### 締切と人数は具体的に
「まもなく締切」ではなく「**7月29日締切、残り3席**」。
ただし**嘘は絶対に書かないでください**（信頼を失うだけでなく、法律の問題にもなります）。

## 公開前のチェック（必ず通す）

| チェック | 内容 |
|---|---|
| ページが開くか | 公開URLを実際に開く |
| 申込ボタン | **全部のボタンが正しい申込先に飛ぶか**（1つずつ押して確認） |
| 書き残し | 「TBD」「未定」「〇〇」のような、書きかけが残っていないか |
| 画像 | 全部表示されるか（リンク切れがないか） |
| スマホ表示 | 実機で見て崩れていないか |
| 誤字 | 日付の曜日・金額・名前 |

**★公開したら記録を残してください。** LPは作るたびに増えて、どこに何があるか分からなくなります。
「LP管理一覧」のような表を1つ作って、作るたびに1行足すことをおすすめします
（ページ名／用途／公開URL／申込先／元ファイルの場所／今の状態）。

## 自分用に直すところ

- 配色・フォント
- 使っている申込システム（申込ボタンのリンク先）
- ヘッダー画像の作り方
