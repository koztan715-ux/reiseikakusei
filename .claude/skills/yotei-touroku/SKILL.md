# 予定を登録する

## これは何？

Googleカレンダーに予定を入れます。
**連続する予定をまとめて入れる**のが得意です（セミナー全6回、面談を20分刻みで10件、など）。

## こう言ってください

```
カレンダーに予定を入れてください。
〇月〇日 20:00〜21:30、タイトルは「△△」です。
```

まとめて入れる場合：

```
面談を20分刻みで入れてください。
10月5日の13時から、10人分。
```

## 登録の仕方（確実な方法）

予定の新規作成は、**あらかじめ内容が入った状態で編集画面を開く**方法が最速で確実です。
時刻の欄を手で打たずに済むので、入力ミスが起きません。開いたら「保存」を押すだけです。

## 気をつけること

### 1. 終了時刻を手で直すとき
終了時刻の欄は、**1回クリックすると中身が全部選択されます**。
その状態で新しい時刻を打って、Enterで確定します。

全選択のショートカットは効きません。既存の文字に混ざって「10:0010:20」のような
壊れた値になり、「無効な時間です」と赤く出ます。

### 2. ドロップダウンに無い時刻も入れられる
20分刻み（10:20など）のような、選択肢に出てこない時刻も、
クリックして全選択 → 打ち込む → Enter、で入ります。

### 3. 連続の予定はバッファを入れるか決めておく
面談や相談を連続で入れるとき、休憩を挟むかどうかは先に決めてください。
**詰めて入れる方針なら、移動時間もゼロで組みます。**

### 4. どのカレンダーに入れるか
複数のカレンダー（仕事用・プライベート）を使っている場合、
**どれに入れるか先に確認してください。**

## 自分用に直すところ

- 使っているカレンダー（アカウントが複数あるなら、どれが既定か）
- 予定のタイトルの付け方
- 通知の設定
