# 確認用の文書を作る

## これは何？

**誰かに見せて、直して、また見せる**——そういう文書の作り方です。

企画書・構成案・報告書・議事録など、1回で完成しない文書はすべてこれで作ります。

## 2つのファイルをセットで作ります

| ファイル | 役割 |
|---|---|
| **〇〇.md** | 正本。直すときはこっちを直す |
| **見るためのページ** | 表や太字が整った読みやすい形。ブラウザで開く |

「.md」のままだと記号だらけで読みにくいので、必ず見やすい形にしてから渡します。

## ★大事なルール：タブを増やさない

直すたびに新しいページを開くと、**タブが何枚も溜まって、どれが最新か分からなくなります**。

そうではなく、**開いているページが自動で新しくなる形**にします。

- 最初に1回だけページを開く
- あとは文書を直すだけ。画面は勝手に新しくなる（1〜2秒）
- スクロールの位置もそのまま

## こう言ってください

```
〇〇の構成案を作ってください。確認用に見られる形で出してください。
```

直すときは、

```
ここをこう直して
```

と言うだけです。画面は勝手に新しくなります。

## 文書の書き方で気をつけること

### 前置きを書きすぎない
「ここで重要なのは」「この項目の狙いは」——**項目の意図説明は原則いりません**。
見出しと中身で伝わります。

### 価値を断定する煽り文を書かない
「〜で決まります」「この企画の生命線です」「ほかの誰も書けない」——
こういう文は**わざとらしく見えます**。迷ったら消してください。

### 自分で自分を評価しない
「意義のある企画だ」ではなく、事実を並べて、判断は相手に委ねます。

## 外部の人に渡すとき

見るためのページはあくまで**自分たちの確認用**です。
お客様や取引先に渡すときは、**PDFにしてから**送ってください。

## 自分用に直すところ

- 保存先のフォルダ
- 見た目（配色・フォント）
- 文体
