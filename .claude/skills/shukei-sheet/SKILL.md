# 集計シートを作る

## これは何？

Googleスプレッドシートで、**数字を入れたら集計まで自動で出る**シートを作ります。

## ★設計の原則：手で入れるのは「生の数字」だけ

これがいちばん大事な考え方です。

| 人がやること | 自動にすること |
|---|---|
| 点数を入れる | 合計・平均を出す |
| 票数を入れる | 順位をつける |
| | 上位者の名前を表示する |
| | 別のシートへ転記する |
| | 並べ替える |

**転記・並べ替え・上位者の抽出・氏名の記入は、全部数式にやらせます。**

### なぜか

手作業の転記は、**本番中に事故ります**。
実際に、集計の本番進行中に「上位者の名前を11枚のシートに手で書き写す」作業が発生し、
時間のロスと入力ミスの危険を生みました。

**「人が入力するセルはどこか」を最初に決めて、それ以外は全部数式にします。**

## こう言ってください

```
集計シートを作ってください。
入れる数字は〇〇で、出したいのは△△です。
```

## よく使う数式

| やりたいこと | 数式 |
|---|---|
| 別のシートから引っぱる | IMPORTRANGE |
| 条件に合う行だけ出す | FILTER |
| 順位をつける | RANK |
| 縦に積み重ねる | VSTACK |
| 条件付きで数える | COUNTIF / COUNTIFS |
| 条件付きで合計 | SUMIF / SUMIFS |

## ★作るときの落とし穴（知らないと必ずハマります）

### 1. 日本語と数式は、入れ方を分ける

| 入れるもの | 方法 |
|---|---|
| 日本語のラベル・見出し | CSVファイルを作ってアップロードする |
| 数式 | 英数字だけで書いて貼り付ける |

**数式をキーボードで打ち込むと、日本語入力がオンのときに `"` `*` `$` が全角になり、
「数式の解析エラー」になります。** これは気づきにくいので注意してください。

### 2. 数式に日本語が必要になったら、設計を変える
日本語を含む条件でCOUNTIFするような作りは、うまくいきません。
**日本語を使わずに済む設計**に変えてください（例：合計から該当分を引く、など）。

### 3. IMPORTRANGE は初回に手で許可が要る
数式を入れただけでは動きません。**1回だけセルをクリックして「アクセスを許可」を押す**必要があります。

### 4. 作ったシートのタイムゾーンを確認する
自動で作ったシートは、タイムゾーンがアメリカになっていることがあります。
ファイル ＞ 設定 ＞ タイムゾーンを東京に直してください。NOW()がずれます。

### 5. 作ったあと、必ず1つ開いて確かめる
行番号を1つ間違えた参照は、パッと見では気づきません。

## 自分用に直すところ

- 入力する項目
- 出したい集計
- シートの分け方（入力用と集計用を分けると事故が減ります）
