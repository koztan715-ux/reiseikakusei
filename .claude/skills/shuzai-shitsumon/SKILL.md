# 取材の質問を作る

## これは何？

人に話を聞きに行くときの質問リストを作ります。

**いちばん大事な考え方：取材は「自由度」が大事です。**
誘導的な質問をすると、想定内の答えしか返ってきません。それでは面白い取材になりません。

## こう言ってください

```
〇〇さんに取材します。質問を作ってください。
テーマは△△で、聞きたいのは□□のあたりです。
```

## いい質問と、よくない質問

### ✕ 選択肢を先に出す
「話しかけられる状態でしたか、それとも近づけない雰囲気でしたか」
→ **二択以外の記憶が引っ込みます**

### ✕ 細かく限定する
「メモはどんな紙に、どれくらいの分量を書いていましたか。前日は何時間練習を？」
→ **紙と時間の話しか出てきません**

### ✕ 仮説をぶつける
「〇〇がきっかけでは？」
→ **相手が仮説に合わせて記憶を語ってしまいます**

### ✕ 前提を含める
「何が足りないと思われましたか」
→ **足りない前提で答えさせています**

### ○ 焦点は当てるが、中身は委ねる
「その頃、本番の前はどんなふうに過ごしていましたか」
→ 場面・時期・相手だけ指定して、**何が起きたかは相手に語らせます**

## 基本の形

- 「どんな〜がありましたか」
- 「そのとき何が起きましたか」
- 「その頃はどんなふうに過ごしていましたか」

この**開いた形**を基本にします。

## 仮説の扱い

仮説を持つのはいいことです。ただし**質問票には書きません。**
取材の場で話が出なければ、最後に確認する程度にとどめます。

事前に渡す資料でも答えを狭めないでください。相手が準備する範囲まで狭まってしまいます。

## 自分用に直すところ

- 質問の数（30〜60分の取材なら8〜12問が目安）
- 相手との距離感（初対面か、よく知っている人か）
- 絶対に外せない確認事項があれば、最後にまとめて置きます
