# 申込の集計をする

## これは何？

申込者のリスト（CSVなど）から、**人数と売上**を出します。

単純に行数を数えるだけでは、**水増しした数字**になります。
このスキルは「数えてはいけない申込」を知っています。

## こう言ってください

```
申込を集計してください。
（申込者リストのファイルを指定する）
```

## ★数えてはいけない申込

### カード事前決済 × 未受領 = キャンセル扱い

**申込はしたけれど、カード決済が通っていない**状態です。
これを数えると、**人数も売上も水増しになります**。

- 申込合計から外す
- 部別・コース別の人数からも外す
- 確定売上からも外す
- 共有する表にも載せない

### ただし「当日現金 × 未受領」は外さない

現金は当日払いなので、**未受領が正常な状態**です。これは数えます。

| 支払方法 | 受領状態 | 数える？ |
|---|---|---|
| カード（事前） | 受領済み | ○ 数える |
| カード（事前） | **未受領** | **✕ 数えない** |
| 当日現金 | 受領済み | ○ 数える |
| 当日現金 | 未受領 | ○ 数える（当日払うので正常） |

### 除外したら、必ず報告する

**黙って消さないでください。**
「除外：〇〇さん／第1部／カード未受領のため」と、**氏名・区分・理由を1行**書き添えます。

あとから「あの人は？」と聞かれたときに、説明できる状態にしておきます。

## 集計で出すもの

- 申込合計（除外後）
- 区分・コース別の人数
- 確定売上
- 前回・前日との差
- 除外した行の一覧

## 気をつけること

### 二重申込
同じ人が複数の区分に申し込んでいることがあります。
片方がキャンセル扱いなら外し、両方有効なら両方数えます。**必ず目で確認してください。**

### 名前の表記ゆれ
「山田太郎」「山田 太郎」「ヤマダタロウ」——同じ人が別人に見えることがあります。

## 自分用に直すところ

- 使っている申込システムのCSVの列名
- 区分の分け方
- 報告先（誰に、どの形で渡すか）
