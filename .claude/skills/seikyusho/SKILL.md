# 請求書を作る

## これは何？

請求書や領収書を作ります。
**毎月同じ相手に出している請求**なら、金額と件数を伝えるだけで作れます。

## こう言ってください

```
〇〇株式会社宛の請求書を作ってください。
今月は△件、単価□円です。
```

## 入れるもの

| 項目 | 備考 |
|---|---|
| 宛名 | 「御中」「様」の使い分けに注意 |
| 請求日 | |
| 請求番号 | 連番にしておくと管理が楽 |
| 品目・数量・単価・金額 | |
| 小計・消費税・合計 | |
| **振込先** | 銀行名・支店名・種別・口座番号・名義 |
| 支払期限 | |
| **発行元**（自分の会社名・住所・連絡先） | |
| **登録番号**（インボイス制度） | ★これが無いと相手が困ります |

## 気をつけること

### 1. 登録番号（インボイス）を必ず入れる
入っていないと、相手の会社が経理処理できません。**あとから再発行を頼まれます。**

### 2. 消費税の計算
税込か税抜か、どちらで話がついているか確認してください。ここの行き違いはよく起きます。

### 3. 領収書は「申込完了と同時」に
イベントなどで領収書が必要な場合、あとから個別に頼まれると全部手作業になります。
**最初から自動で送る**設定にしておくのが正解です。

### 4. 毎月同じ請求は、前月分をコピーして日付と数量だけ変える
ただし**コピーしたら必ず全部見直してください**。前月の日付や金額が残る事故が多いです。

## 自分用に直すところ

- ★発行元の情報（会社名・住所・電話・登録番号・振込先）
  → **最初に1回書いておけば、次からは毎回入ります**
- 請求書のデザイン
- 請求番号の付け方
- 送り方（PDFをメール／郵送）
