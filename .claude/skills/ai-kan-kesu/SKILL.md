# 文章のAI感を消す

## これは何？

AIに書かせた文章は、内容は合っていても「いかにもAIが書いた感じ」が残ります。
このスキルは、その**におい**を消して、人が書いたように直します。

文章を見せてもらえば、どこがAIっぽいかを指摘して、直した文章を出します。

## こう言ってください

```
この文章のAI感を消してください。
（文章を貼るか、ファイルを指定する）
```

## 消すもの（AIっぽさの正体）

### 1. 中身のない形容
「圧倒的な」「本質的な」「まさに」「非常に」——
外しても意味が変わらない飾りは、**全部消します**。

### 2. メタな強調
「ここで重要なのは」「注目すべきは」「ポイントは」——
読み方を指図する言葉です。大事なことは、書けば伝わります。

### 3. 強調のインフレ
太字・「★」・「！」が多すぎると、どれも目立たなくなります。
本当に強調したい1か所だけ残します。

### 4. キメすぎのパターン
「〜ではないだろうか」「〜なのかもしれない」で毎回締める。
一文を短く切って余韻を出す型を繰り返す。——**同じ締め方を2回使ったら、片方を変えます。**

### 5. 文頭・文末のワンパターン
段落の頭が毎回「しかし」「つまり」「そして」。
文末が毎回「〜である」「〜だ」。——並べてみて、同じ形が続いていたら崩します。

### 6. 三段言い換え
「つまり、言い換えれば、要するに」と同じことを3回言う癖。
**一発で言えることは一発で言います。**

### 7. 「――」（ダッシュ）の多用
1つの文章に何度も出てきたら、ほとんどは読点か句点で足ります。

### 8. エビデンスの盛りすぎ
研究・データ・著名人の言葉を毎項目に入れると、かえって薄く見えます。
本当に効く1つだけ残します。

### 9. 読点の打ちすぎ
「まず、型から、入る。」——短い語のあとに刻みすぎです。
**1文に読点0〜2個**が基本。20〜25字に1つくらいが自然です。

### 10. 「Aさん」「Bさん」のラベル
例え話の登場人物を記号にすると、途端に嘘っぽくなります。
具体的な場面で書くか、自分の体験にします。

## 目指す方向

| ✕ AIっぽい | ○ 人が書いた感じ |
|---|---|
| 整いすぎた書き言葉 | 生の口語感 |
| 抽象的 | 具体的 |
| 三段で言い換える | 一発で言う |
| メタに解説する | 直接書く |

## やらないこと

- **内容を変えない**（言い回しを直すだけで、主張や事実は動かしません）
- 引用文の中は触らない（原文のままにします）
- 短くすることが目的ではありません（削って意味が痩せるなら残します）

## 自分用に直すところ

- 文体（です・ます／だ・である）
- 一人称（僕／私／筆者）
- 残したい口癖があれば先に伝えてください（それは「味」なので消しません）
