# Zoom待機室の画像を替える

## これは何？

Zoomの待機室（参加者が入室前に見る画面）の画像を差し替えます。
イベントごとに変えると、開始前から世界観が伝わります。

※有料アカウント限定の機能です。

## ★最初に確認すること

### 1. 待機室の画像は「アカウント全体で共通」です
**ミーティングごとに設定することはできません。**
一度変えると、**すべてのミーティングで同じ画像**になります。

イベントが終わったら戻す予定があるか、先に決めておいてください。
差し替える前に、**今の画像が何かを控えておく**ことをおすすめします。

### 2. 元の画像がどこにあるか

## 画像の条件

| 項目 | 条件 |
|---|---|
| 形式 | **JPEG推奨**（PNGは失敗しやすい） |
| 容量 | **1MB以下** |
| 最小サイズ | 400×200 |
| 比率 | **2:1 推奨** |

### 16:9の画像（1920×1080）を使うとき
上下を切って **1920×960（2:1）** にします。
文字やQRコードが切れない位置で切ってください。

### ★PNGではなくJPEGにする
**元が1MB以下のPNGでも、アップロードで失敗します。**
Zoomの切り抜き画面が画像を作り直すため、1MBを超えてしまうからです。

**200〜400KBのJPEG**にしてください。実際に、753KBのPNGが失敗して、207KBのJPEGで成功しています。

## 手順

1. 画像を2:1に切る
2. JPEGにして、200〜400KBに落とす
3. Zoomの設定画面で差し替える
4. **実際に待機室に入って確認する**

## QRコードが入っている画像のとき

変換したあとに、**QRコードが読み取れるか必ず確認してください。**
切り取りや圧縮で読めなくなることがあります。

## 自分用に直すところ

- 使っているZoomアカウント（複数あるなら、どれか確認します）
- 通常時に戻す画像の場所
