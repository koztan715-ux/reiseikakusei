# 取材・対談を整理する

## これは何？

取材や対談の文字起こしを、**読める形に整えます**。

**いちばん大事なこと：まとめません。要約しません。並べ替えません。**
誰が何を言ったかが、言葉どおりに分かる形で残します。

## なぜ要約しないのか

取材の価値は、**生の言い回しと具体的な話**にあります。
要約すると、原稿に使えるディテールが全部落ちます。
原稿は発言そのものから起こすので、整理の段階で情報を縮めてはいけません。

## こう言ってください

```
この取材を整理してください。
（文字起こしファイルを指定する）
```

## 削っていいもの

- 「えー」「あの」「なんか」などの言い淀み
- 意味のない相づち（「うん」「はい」だけの発言）
- 音声認識が英語に化けた相づち（Hmm／Right／Mmhm など）

## 直していいもの

- 口頭ゆえの言い間違い・言い直し
- 音声認識の誤変換（人名・固有名詞の取り違えなど）
- **判断に迷った固有名詞は直さず「※要確認」を付けて残す**

## 変えてはいけないもの

- **発言の順番・前後関係**
- **発言者**
- 複数の発言をまとめること
- テーマ別に集約すること
- 見出しを立てて再構成すること

## 出力の形

```
話者：発言
話者：発言
（5分ごとくらいに時刻を残す）
```

発言順にそのまま並べます。

**決定事項・宿題・要確認の一覧が必要なときは、整理したものとは別のファイルにします。**
整理版の中に混ぜません。

## 自分用に直すところ

- 保存先のフォルダとファイル名の付け方
- 時刻を残す間隔
- 話者名の表記（「岡崎」「岡崎さん」など）
