# 読みやすい文章に整える

## これは何？

長い文章を書くと、必ず2つのことが起きます。

1. **読点（、）が多すぎる**
2. **同じ言葉の書き方がバラバラになる**（「一番」と「いちばん」が混在するなど）

このスキルは、その2つを直します。**内容は一切変えません。**

## こう言ってください

```
この文章を読みやすく整えてください。
（ファイル名を指定するか、文章を貼る）
```

## 1. 読点を減らす

### 目安
- **1文に読点0〜2個**
- 文字数でいうと、**20〜25字に1つ**くらいが自然

### 直す例
| ✕ 打ちすぎ | ○ 自然 |
|---|---|
| まず、型から、入る。 | まず型から入る。 |
| そこで、私は、あえて、何もしなかった。 | そこで私は、あえて何もしなかった。 |

### 気をつけること
- **削るのは読点だけ**。語句・語順・内容は変えません
- 句点（。）の数＝文の数は変えません
- 引用文（「」の中）の読点は原文なので触りません

## 2. 表記を揃える

同じ言葉が2通りで書かれていたら、片方に統一します。
**迷ったら、ひらがな側に揃えます**（読者が目で滑らかに読めるほうを優先するため）。

### ひらがなに揃えるもの
あける／いちばん（副詞のとき）／ほうが／ない／とき／こと／もの／という／ください／わかる／すべて／たくさん／いただく

### 漢字のままにするもの
- **言う** — 実際に発言する意味のとき（「正直に言うと」）。※「〜という」はひらがな
- 同時に／同じ — ひらがなにすると読みにくい語
- 数を数える語（「1つ目」「14の項目」）

### 数字は算用数字
1, 2, 3… を基本にします。ただし「第一印象」「一石二鳥」のような慣用句は例外です。

## 作業のしかた（大事）

表記ゆれを直すときは、**機械的に置き換えてはいけません**。
「仕事が」「同時に」「自分から」のような、関係ない言葉まで壊れます。

1. ゆれている候補を両方数える（一番／いちばん、方が／ほうが、無い／ない…）
2. **混在しているものだけ**を対象にする
3. 1か所ずつ前後を見て、置き換えていいか確認する

## 自分用に直すところ

- ひらがなに揃える語のリスト（自分の文体に合わせて足し引きしてください）
- 文体（です・ます／だ・である）
- 読点の目安（20〜25字が基本。もっと少なくしたい人は伝えてください）
