# 音声を文字起こしする

## これは何？

録音した音声や動画を、文字にします。

**自分のパソコンの中だけで処理します。** つまり——

- **無料**（月額のサービスが要りません）
- **中身が外に出ない**（取材・打ち合わせ・相談など、外に出せない音声も安心）
- 何時間でも、何本でも

## ⚠️ はじめに1回だけ、準備が必要です

このスキルは、**別のソフトを入れないと動きません。**

| | |
|---|---|
| **時間** | 15〜30分（初回だけ。2回目からは不要） |
| **パスワード** | 途中でパソコンのパスワードを聞かれます。**そこだけはご自分で打ってください**（クロードコードは打てません） |
| **容量** | 1GBほど使います |
| **Windowsの方** | Macより手順が増えます。うまくいかない場合はセミナーで質問してください |

### 準備のしかた

こう言ってください。

```
文字起こしの道具をそろえてください。
```

クロードコードが、何が必要か確認して、入れるところまで案内します。
（「dogu-soroeru」スキルが動きます）

## 使い方

準備が終わったら、こう言うだけです。

```
この音声を文字起こししてください。
（ファイルを指定する）
```

## 精度を上げるコツ

**出てくる人名・会社名・専門用語を、先に伝えてください。**

```
この音声を文字起こしして。
出てくる名前は「〇〇さん」「△△株式会社」「□□法」です。
```

これだけで、固有名詞の精度がかなり変わります。

## 文字起こしのあと

出てきた文章は、そのままでは読みにくいことが多いです。目的に応じて次へ進めます。

- **取材・対談** → 「shuzai-seiri」スキルで、発言のまま読める形に整える
- **記事にする** → そのまま原稿化を頼む
- **議事録** → 決定事項と宿題を抜き出してもらう

## 自分用に直すところ

- よく出てくる固有名詞のリスト（毎回伝えなくて済むように、書いておくと便利です）
- 音声ファイルの置き場所
- 出力の保存先
