# ルール見本帳

## これは何？

**「毎回こうして」の実例集**です。同じフォルダの `見本帳.md` に32本入っています。

そのままコピーして、自分の CLAUDE.md に貼れます。

## 使い方

### 全部見たいとき
```
ルール見本帳を見せてください。
```

### 自分に合うものを選んでほしいとき
```
私の仕事は〇〇です。見本帳から合いそうなルールを選んでください。
```

### 取り込むとき
```
見本帳の△△と□□を、私のCLAUDE.mdに入れてください。
```

## ★全部入れないでください

**CLAUDE.mdは毎回読まれます。** 長すぎると大事なことが埋もれます。

- まず**5〜10本**だけ入れる
- 使ってみて「これは要らない」と思ったら消す
- 「また同じこと言ってるな」と思ったら足す

**育てるものだと思ってください。**

## 自分の言葉に書き換えてください

見本帳のルールは、そのままでも使えますが、
**自分の仕事の言葉に直したほうが効きます。**

例：「数字は算用数字が基本」→「金額と日付は必ず算用数字。商品コードは半角英数」
