# 毎朝決まった時間に動かす

## これは何？

**毎日・毎週やっている作業を、決まった時間に勝手にやらせます。**

- 毎朝7時に、メールを見て要返信のものを教えてもらう
- 毎週水曜に、申込状況を集計してシートを更新する
- 毎月3日に、先月の領収書を集める

パソコンが起動していれば、自分が何もしなくても動きます。

## こう言ってください

```
毎朝7時に〇〇をするルーチンを作ってください。
```

## ★作るときの大事な設定

### 「許可をバイパス」にする

ルーチンは、**自分がパソコンの前にいないときに動きます。**

そのとき「これをやっていいですか？」と確認が出ると、**そこで止まってしまいます。**
誰も「はい」を押せないからです。

なので、ルーチンは必ず**確認なしで動く設定**にします。

## ルーチンに向いているもの・向いていないもの

| 向いている | 向いていない |
|---|---|
| 毎回同じ手順のもの | その日によって判断が変わるもの |
| 見る・集める・まとめる | **外部に送る**（メール送信・投稿） |
| 下書きまで作る | お金が動くもの |

### ★送信までは自動にしないのがおすすめ

メールの**下書きまで**作らせて、**送信ボタンは自分が押す**。
この形が、いちばん安全で、いちばん使えます。

間違ったメールが自動で送られる事故は、取り返しがつきません。

## 作るときに決めること

1. **いつ動かすか**（毎日／毎週／毎月、何時）
2. **何をするか**（手順を具体的に）
3. **結果をどう知らせるか**（メール／通知／何もしない）
4. **何もなかったときも知らせるか**
   → ★「0件のときは何も送らない」にすると、通知が意味を持ちます

## 作ったあと

### 動いているか確認する
最初の数日は、ちゃんと動いたか見てください。
動いていなければ、時間の設定かパソコンの状態（スリープなど）を見直します。

### 使わなくなったら止める
役目を終えたルーチンを放っておくと、動き続けます。
**止めて、片付けてください**（「soko-shimau」スキルが使えます）。

## 自分用に直すところ

- 動かす時刻（少しずつずらすと、同時に動いて重くなるのを防げます）
- 知らせ方
- パソコンの設定（スリープしていると動きません）
