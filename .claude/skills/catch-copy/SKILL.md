# キャッチコピーを出す

## これは何？

商品やイベントを説明してもらうと、**15字以内のキャッチコピーを10本**出します。
ただ思いつきを並べるのではなく、決まったチェックに通ったものだけを出します。

## こう言ってください

```
キャッチコピーを考えてください。
売りたいのは〇〇で、届けたい相手は△△な人です。
締切は□月□日、価格は〜です。
```

## 大原則

- **15文字以内が黄金**（これを超えたら削る）
- 1文は40字以内
- 結論・相手の得を先頭に置く
- **具体的な数字を必ず入れる**
- 万人受けを狙わない（相手を絞ったほうが刺さる）
- 1つのコピーで言うことは1つだけ

## 出す前のチェック（ここを通らない案は捨てる）

### PAS＋4U で確認する

**PAS** = 問題 → 掘り下げ → 解決
**4U** = 有用性・緊急性・超具体性・独自性

この2つに当てはまらない案は、その場でボツにします。

| 判定 | 例 | なぜ |
|---|---|---|
| ✕ ボツ | 「急げ！」 | 漠然としている。4Uが全部ない |
| △ 弱い | 「締切迫る」 | 緊急性だけ。具体性がない |
| ○ 合格 | 「7/29締切、残り3席」 | 超具体性＋緊急性＋希少性 |
| ○ 合格 | 「本になる1人を決める10日間」 | 対比＋物語＋希少性 |

## 使える型

### 3つの刺し方
- **共感型** — 言いたいけど言えない感情を代弁する（好意・信頼が育つ）
- **期待外れ型** — 予想を裏切って注意を引く（記憶に残る・広まる）
- **痛点突き型** — 損したくない気持ちを突く（すぐ動いてもらう）

### 心理トリガー8つ
1. 具体的に呼びかける（「40代の乾燥肌でお悩みの方へ」）
2. 不安→安心をセットで（「30日間全額返金保証」）
3. みんなやっている（「3人に1人がリピート」）
4. 数値を身近なものに例える（「キャベツ10個分の食物繊維」）
5. 権威を借りる（「東大の研究で証明」）
6. 禁止して欲しがらせる（「本当に価値がわかる人だけに」）
7. 比較価格を見せる（「通常5万円→今だけ半額」）
8. 数と期限を切る（「限定30セット」「7/29締切」）

### 見出しの型7つ
数字型／疑問型／How to型／ネガティブ型／証言型／対比型／限定型

## やってはいけないこと

- 15字を超える（記憶に残りません）
- 痛いところを突くだけで、解決策を見せない（反感を買います）
- 万人受けを狙う（誰にも刺さりません）
- **根拠のない「限定」「No.1」**（信頼を失うだけでなく、法律の問題にもなります）
- 不安を煽りすぎる
- 特徴を並べただけで終わる（「創業50年」→「半世紀の知見が課題解決を加速」に翻訳する）

## 直すときの優先順位

反応が悪いときは、この順番で直すと効きます。

1. **見出し**（影響が極大）
2. ボタンの文言
3. メールの件名
4. リード文
5. 入力フォームの文言

## 自分用に直すところ

- 出す本数（既定は10本）
- 字数の上限（15字が基本。媒体によっては20字まで）
- 使わない言葉（自分のブランドに合わない表現があれば先に伝えてください）
