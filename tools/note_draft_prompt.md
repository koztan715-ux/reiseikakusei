# note販売記事 生成プロンプト（セミナーアーカイブ用）

文字起こしテキストができたら、このテンプレートをそのままClaude Codeに貼り付けて
「この文字起こしからnote記事を作って」と依頼する。毎回同じ構成で下書きが出るので、
複数のアーカイブを継続販売する際も品質と作業手順がぶれない。

---

## 依頼プロンプト（コピーして使う）

```
以下はセミナーアーカイブの文字起こしです。この内容をもとに、note（有料記事）の
販売ページ用テキストを作成してください。

【ブランド情報】
- スクール名: 櫻桃ビジネススクール サテライトキャンパス新潟校
- 講師: 佐川朋子
- テーマ: 潜在意識・潜在能力の覚醒による人生の変容
- トーン: 温かく背中を押すが、誇大表現や医療的/断定的な効果保証はしない

【出力してほしい構成】
1. タイトル案（3案、32文字以内、検索されやすいキーワードを含む）
2. キャッチコピー（1〜2行、フックになる悩み提起）
3. こんな人におすすめ（箇条書き3〜5個）
4. このアーカイブで得られること（箇条書き3〜5個、具体的な変化ベースで）
5. 目次・章立て（文字起こしの内容から自然に区切って作成、各章に一言説明を添える）
6. 講師紹介文（100字程度、文字起こし内で講師が話した実績・経歴があれば反映）
7. 価格帯の提案（note内の類似ジャンル相場を踏まえて2〜3パターン、根拠も添える）
8. よくある質問（Q&A形式で3〜4個、購入前の不安を解消する内容）
9. 購入ボタン直前のクロージング文（1段落）

【禁止事項】
- 文字起こしにない実績や効果を創作しない
- 断定的な医療効果・確実性を示す表現は使わない（薬機法・景表法に配慮）
- 誇大広告的な表現（「絶対」「必ず」等）は避ける

--- 文字起こし本文 ---
（ここに tools/transcribe.py の出力（.txt）を貼り付ける）
```

---

## 運用の流れ（アーカイブが増えるたびに繰り返す）

1. 録画/録音ファイルを用意する
2. `python3 tools/transcribe.py <ファイル名>` で文字起こし（`.txt` が生成される）
3. 上記プロンプトの「文字起こし本文」部分に `.txt` の中身を貼り付けてClaude Codeに依頼
4. 出てきた下書きを確認・微調整し、noteに手動で貼り付けて公開

文字起こし〜下書き生成までは自動化・半自動化できるが、note.comへの実際の投稿・
価格設定の最終判断・法令表現のチェックは必ず人が行うこと。
